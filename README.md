# OlafxVlog — portfolio wideo

Portfolio OlafxVlog prezentuje ofertę, etapy współpracy, realizacje wideo, zdjęcia z planów i krótką stronę o autorze. Układ jest przygotowany z myślą o czytelności na telefonie i komputerze.

## Podgląd

Po włączeniu GitHub Pages strona będzie dostępna pod adresem:

**https://olafxvlog.github.io/portfolio-park/**

Repozytorium jest publiczne, więc można też udostępnić bezpośrednio ten adres GitHub.

## O projekcie

Oryginalna witryna jest edytowana w WordPressie za pomocą bloków. Podstrona realizacji zawiera sześć bloków YouTube do uzupełnienia własnymi adresami. Galerię zdjęć można rozbudować, dodając zdjęcia w edytorze WordPressa.

Folder `docs/` zawiera statyczny podgląd przygotowany do publikacji w GitHub Pages. Aktualizację podglądu można wygenerować ponownie, gdy lokalny WordPress działa, uruchamiając `python3 export_for_github.py`.

GitHub Pages nie uruchamia WordPressa ani PHP. Dlatego formularz na statycznym podglądzie nie wysyła wiadomości; zamiast tego kieruje do profilu Instagram. Do kontaktu można też użyć profili:

- [Instagram OlafxVlog](https://www.instagram.com/olafxvlog/)
- [Instagram OlafxVlog Video](https://www.instagram.com/olafxvlog_video/)
- [YouTube OlafxVlog](https://www.youtube.com/@OlafxVlog)
- [TikTok OlafxVlog](https://www.tiktok.com/@olafxvlog)

Zdjęcia i materiały graficzne użyte przez witrynę znajdują się w `docs/wp-content/uploads/`.
