# OlafxVlog — portfolio wideo

Portfolio prezentuje zakres usług OlafxVlog: filmy promocyjne, teledyski, materiały na YouTube i relacje z wydarzeń. Zawiera stronę główną, stronę oferty oraz odnośniki do profili na Instagramie.

## Podgląd

Po włączeniu GitHub Pages strona będzie dostępna pod adresem:

**https://olafxvlog.github.io/portfolio-park/**

Repozytorium jest publiczne, więc można też udostępnić bezpośrednio ten adres GitHub.

## O projekcie

Oryginalna witryna jest edytowana w WordPressie. Ten folder `docs/` zawiera statyczny podgląd przygotowany do publikacji w GitHub Pages. Aktualizację podglądu można wygenerować ponownie, gdy lokalny WordPress działa, uruchamiając `python3 export_for_github.py`.

GitHub Pages nie uruchamia WordPressa ani PHP. Dlatego formularz na statycznym podglądzie nie wysyła wiadomości; zamiast tego kieruje do profilu Instagram. Do kontaktu można też użyć profili:

- [OlafxVlog](https://www.instagram.com/olafxvlog/)
- [OlafxVlog Video](https://www.instagram.com/olafxvlog_video/)

Zdjęcia i materiały graficzne użyte przez witrynę znajdują się w `docs/wp-content/uploads/`.
